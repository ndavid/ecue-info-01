Ces pages détaillent comment vérifier que les outils nécessaires au module
fonctionnent sur les postes de la salle. Trois vérifications, à faire dans
l'ordre : le réseau, les logiciels de texte et de bureautique, puis Anaconda.
Chaque page dit ce qu'on fait, ce qu'on doit voir, et quelle entrée des
annexes lire si on ne le voit pas.

La configuration des outils plus poussés (JupyterLab, VS Code et ses
extensions) est détaillée dans les annexes, ainsi que l'installation sur un
ordinateur personnel.
